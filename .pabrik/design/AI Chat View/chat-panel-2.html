Great question — this is where the math gets interesting. The trick is to compute the snap delta based on the **union bbox of the selection**, not the dragged card.

Here's the shape of the function I'd suggest:
// computeSnapDelta(selection: Set<Card>): {dx, dy} | null
const union = bboxOf(selection);
for (other of cards.filter(c => !selection.has(c))) {
  const d = nearestEdgeDelta(union, other);
  if (d !== null && Math.abs(d.dx) < SNAP_PX) return d;
}
The SNAP_PX constant lives in your design tokens — Kanagawa uses 6 design-px which is Figma's default. Want me to apply this to KanbanColumn.vue directly?
