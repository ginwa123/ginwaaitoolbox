Wireframe v2 — /skill- autocomplete

Type /skill → the full skill list opens. Type the dash - and keep typing → it filters (/skill-co → code-review, commit-msg). Bare / works too. @ still opens files.
Compactmuse spark auto114k / 900k

1. Trigger. /skill opens the whole skill list. After the dash -, each letter filters it. (A bare / opens it too; http:// never triggers because the / must sit at message start or after a space.)

2. Autocomplete. Up/Down move, Enter/Tab accept, Esc closes.

3. Insert. Accepting from /skill-co inserts /skill-code-review as plain text — keep typing around it, mix @file + /skill-x in one message.

4. Send. The backend sees /skill-code-review, loads that skill server-side. Unknown names stay as literal text + a toast.
