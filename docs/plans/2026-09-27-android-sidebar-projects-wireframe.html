Wireframe — Android drawer · Projects section

Mirrors the Vue sidebar's ProjectsList on a 390dp phone. The workspace dropdown, the Recent list and the account footer are unchanged; the whole feature is the block between them.

Confirmed Tap a Project row → it expands in place, drawer stays open (a project is a filter, not a destination — README.md §Drawer: only a chat closes the drawer). Tap See all chats › → the drawer closes and a new screen opens, which lazy-loads on scroll. Plan: docs/plans/2026-09-27-android-sidebar-projects-menu.md

A task row's id is the session id (the backend's own convention, http_response.zig). That is why a project expands straight into openable chats with no join and no second lookup — and why the drawer preview and the new screen can share one fetched page instead of fetching twice.

6 · Explicitly not in this wireframe

  • No + Add Item menu. Vue has four live options (Kanban, Design, Agent, Routine). Creating a project from a phone is its own card.
  • No counts anywhere. Not on a collapsed project row, not on the See all chats › button, not in the new screen. The tasks endpoint returns count = page length, not a total, so an honest number costs paging the whole list — per project, per refresh. The only number the UI ever prints is the one the page in hand proves: the footer's Scroll for older chats → No older chats flip.
  • No project board / agent config / design canvas. The new screen lists chats. Tapping a project row never navigates; only See all chats › does.
  • No delete / rename / reorder / drag-and-drop. A phone is the wrong surface for reordering a tree.
  • No two independent scrollers in the drawer. Vue makes the Recent pane resizable and gives Projects flex-1. On 390dp that leaves Recent about four rows tall, so both live in one LazyColumn. The new screen is a second scroller, but it is a whole screen, not a pane.
  • No folder file listing. Vue fetches GET /api/system/folder?action=list&path=… for a folder project; here a folder project just expands to its chats like every other type.
