# `nalar-desktop` Webview Wrapper — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a new Zig executable `nalar-desktop` that wraps the existing `nalar` HTTP server in a native webview window. The webview loads `http://127.0.0.1:<port>/` (served by nalar, which serves both the embedded Vue dist/ and the existing `/api/*` endpoints). On window close, the wrapper kills nalar and exits.

**Architecture:** A small Zig binary (~1500 LOC total) spawns `nalar` as a child process on a free port, waits for its health endpoint, opens a native webview window pointed at the local URL, runs the platform event loop, and tears the child down on close. Three platform implementations (Linux WebKitGTK in pure Zig, macOS WKWebView via Objective-C++ shim, Windows WebView2 via C++ shim) all expose the same C ABI.

**Tech Stack:** Zig 0.15, WebKitGTK 4.1 + GTK 3 (Linux), Cocoa + WebKit (macOS), WebView2 + Win32 (Windows), the existing `httpz` for nothing in this binary (nalar has it), Bun for building the Vue dist.

**Prerequisites:**
- **Plan A** (`docs/superpowers/plans/2026-06-10-nalar-static-dir.md`) must be **merged** first — nalar needs the `--static-dir` flag to serve the embedded Vue dist.
- **Design doc** (`docs/plans/2026-06-10-desktop-webview-app-design.md`) is the source of truth for the architecture and CLI surface.

**Plan structure:** This plan is split into 9 chunks. Each chunk produces working, testable code on its own. Execute them in order; later chunks depend on earlier ones.

## Decisions locked in by this plan

- **Platform-specific code is the only way to keep this maintainable.** The 3 platform implementations live in `platform/<os>.zig` + a small native shim for macOS/Windows. The shared C header in `shared/webview_c.h` is the source of truth.
- **All platform shims implement the same 3 C functions:** `nalar_webview_create`, `nalar_webview_run`, `nalar_webview_destroy`. The Zig side declares them as `extern "c"` and calls them through a single API.
- **Asset extraction is the simplest path that works.** v1 extracts the embedded Vue dist/ to a per-user temp dir before spawning nalar. nalar (with the Plan A `--static-dir` flag) serves it. v2 can switch to in-process embedding (Option β in the design doc) if single-binary distribution becomes a requirement.
- **The webview is a pure window — zero JS↔Zig IPC in v1.** The webapp is 100% unchanged. The webview's only job is to be a window.
- **Dev workflow is unchanged.** Devs use `bun dev` + `nalar` in a browser. `nalar-desktop` is a release-only artifact.
- **One binary, two-process model.** `nalar-desktop` and `nalar` are separate executables. Resolution: `--nalar-path` → next to self → `$PATH`.
- **The smoke test (`--smoke-test` mode) is CI-friendly.** On Linux it runs under Xvfb; on macOS/Windows on the native display.

```zig
// src/apps/desktop_app/port.zig
const std = @import("std");

pub const FreePort = struct {
    port: u16,
    /// For debugging only; the OS may recycle the port after we close our probe socket.
    path: ?[]u8 = null,
};

/// Find a free TCP port on the loopback interface by binding to port 0
/// and reading the OS-assigned port back. The socket is closed before returning,
/// which creates a small race window — callers that need a held reservation should
/// wrap this in their own protocol.
pub fn findFree(allocator: std.mem.Allocator) !FreePort {
    const address = try std.net.Address.parseIp("127.0.0.1", 0);
    const server = try std.net.tcpListenToAddress(address);
    defer server.deinit();
    const port = server.listen_address.getPort();
    return .{ .port = port, .path = null };
}
```

```zig
// src/apps/desktop_app/cli.zig
const std = @import("std");

pub const Config = struct {
    /// Port to bind nalar on. 0 = auto-pick a free port.
    port: u16 = 0,
    /// Optional explicit path to the nalar binary.
    nalar_path: ?[]const u8 = null,
    /// Window dimensions.
    window_width: u32 = 1280,
    window_height: u32 = 800,
    /// Window title.
    title: []const u8 = "Nalar",
    /// Optional User-Agent override.
    user_agent: ?[]const u8 = null,
    /// Optional path to a window icon.
    icon_path: ?[]const u8 = null,
    /// If true, the app runs in CI-friendly mode: open, wait briefly, exit.
    smoke_test: bool = false,

    pub fn deinit(self: *Config, allocator: std.mem.Allocator) void {
        if (self.nalar_path) |p| allocator.free(p);
        if (self.title.len > 0 and !std.mem.eql(u8, self.title, "Nalar")) allocator.free(self.title);
        if (self.user_agent) |ua| allocator.free(ua);
        if (self.icon_path) |ip| allocator.free(ip);
    }
};

pub const CliError = error{
    ShowHelp,
    InvalidPort,
    InvalidSize,
    MissingValue,
};

const usage =
    \\Usage: nalar-desktop [options]
    \\
    \\Options:
    \\  --port PORT              Port for nalar to bind on (default: 0 = auto-pick)
    \\  --nalar-path PATH        Explicit path to nalar binary
    \\  --window-size WxH        Window size in pixels (default: 1280x800)
    \\  --title TITLE            Window title (default: "Nalar")
    \\  --user-agent UA          User-Agent string for the webview
    \\  --icon PATH              Path to window icon
    \\  --smoke-test             Open, wait 2s, exit (for CI)
    \\  --help, -h               Show this help
    \\
;

pub fn parse(allocator: std.mem.Allocator, args: []const []const u8) CliError!Config {
    var cfg: Config = .{};
    errdefer cfg.deinit(allocator);

    var i: usize = 1; // skip argv[0]
    while (i < args.len) : (i += 1) {
        const arg = args[i];
        if (std.mem.eql(u8, arg, "--port")) {
            i += 1;
            if (i >= args.len) return error.MissingValue;
            cfg.port = std.fmt.parseInt(u16, args[i], 10) catch return error.InvalidPort;
        } else if (std.mem.eql(u8, arg, "--nalar-path")) {
            i += 1;
            if (i >= args.len) return error.MissingValue;
            cfg.nalar_path = try allocator.dupe(u8, args[i]);
        } else if (std.mem.eql(u8, arg, "--window-size")) {
            i += 1;
            if (i >= args.len) return error.MissingValue;
            const x_idx = std.mem.indexOfScalar(u8, args[i], 'x') orelse return error.InvalidSize;
            const w = std.fmt.parseInt(u32, args[i][0..x_idx], 10) catch return error.InvalidSize;
            const h = std.fmt.parseInt(u32, args[i][x_idx + 1..], 10) catch return error.InvalidSize;
            cfg.window_width = w;
            cfg.window_height = h;
        } else if (std.mem.eql(u8, arg, "--title")) {
            i += 1;
            if (i >= args.len) return error.MissingValue;
            if (cfg.title.len > 0 and !std.mem.eql(u8, cfg.title, "Nalar")) allocator.free(cfg.title);
            cfg.title = try allocator.dupe(u8, args[i]);
        } else if (std.mem.eql(u8, arg, "--user-agent")) {
            i += 1;
            if (i >= args.len) return error.MissingValue;
            if (cfg.user_agent) |ua| allocator.free(ua);
            cfg.user_agent = try allocator.dupe(u8, args[i]);
        } else if (std.mem.eql(u8, arg, "--icon")) {
            i += 1;
            if (i >= args.len) return error.MissingValue;
            if (cfg.icon_path) |ip| allocator.free(ip);
            cfg.icon_path = try allocator.dupe(u8, args[i]);
        } else if (std.mem.eql(u8, arg, "--smoke-test")) {
            cfg.smoke_test = true;
        } else if (std.mem.eql(u8, arg, "--help") or std.mem.eql(u8, arg, "-h")) {
            const stderr = std.fs.File.stderr();
            stderr.writeAll(usage) catch {};
            return error.ShowHelp;
        } else {
            const stderr = std.fs.File.stderr();
            var buf: [256]u8 = undefined;
            const msg = std.fmt.bufPrint(&buf, "Unknown argument: {s}\n\n{s}", .{ arg, usage }) catch usage;
            stderr.writeAll(msg) catch {};
            return error.UnknownArg;
        }
    }
    return cfg;
}
```

```zig
// src/apps/desktop_app/path_resolve.zig
const std = @import("std");

/// Resolve the path to the nalar binary. Resolution order:
/// 1. explicit_path (if non-null and the file exists)
/// 2. <dir_of_self_exe>/nalar
/// 3. nalar in $PATH
/// Returns null if nothing was found.
pub fn resolve(
    allocator: std.mem.Allocator,
    explicit_path: ?[]const u8,
    self_exe_path: []const u8,
    path_env: []const u8,
) ?[]u8 {
    // 1. Explicit path
    if (explicit_path) |p| {
        if (fileExists(p)) {
            return allocator.dupe(u8, p) catch null;
        }
    }

    // 2. Next to self
    if (std.fs.path.isAbsolute(self_exe_path)) {
        const self_dir = std.fs.path.dirname(self_exe_path) orelse ".";
        const candidate = std.fs.path.join(allocator, &.{ self_dir, "nalar" }) catch return null;
        defer allocator.free(candidate);
        if (fileExists(candidate)) {
            return allocator.dupe(u8, candidate) catch null;
        }
    }

    // 3. PATH lookup
    var it = std.mem.tokenizeScalar(u8, path_env, ':');
    while (it.next()) |dir| {
        const candidate = std.fs.path.join(allocator, &.{ dir, "nalar" }) catch continue;
        defer allocator.free(candidate);
        if (fileExists(candidate)) {
            return allocator.dupe(u8, candidate) catch continue;
        }
    }
    return null;
}

fn fileExists(path: []const u8) bool {
    std.fs.accessAbsolute(path, .{}) return true else |_| return false;
}
```

```zig
// src/apps/desktop_app/subprocess.zig
const std = @import("std");
const builtin = @import("builtin");

/// Handle to a running nalar subprocess.
pub const NalarProcess = struct {
    child: std.process.Child,
    port: u16,
    pid: std.process.Child.Id,

    /// Send SIGTERM, wait up to 2s, then SIGKILL if still alive.
    pub fn terminate(self: *NalarProcess) void {
        self.child.kill() catch {};
        // Wait for the child to actually exit
        const term = self.child.wait() catch .{ .signal = 0 };
        _ = term;
    }
};

/// Poll http://127.0.0.1:<port>/api/health until it returns 200 or the timeout expires.
pub fn waitForHealth(
    allocator: std.mem.Allocator,
    port: u16,
    timeout_ms: u32,
    poll_ms: u32,
) !void {
    const deadline = std.time.milliTimestamp() + timeout_ms;
    var last_err: anyerror = error.ConnectionRefused;

    while (std.time.milliTimestamp() < deadline) {
        // Use a 1-second connect timeout per attempt
        const stream = std.net.tcpConnectToAddress(
            try std.net.Address.parseIp("127.0.0.1", port),
        ) catch |err| {
            last_err = err;
            std.Thread.sleep(poll_ms * std.time.ns_per_ms);
            continue;
        };
        defer stream.close();

        // Send HTTP request
        const req = "GET /api/health HTTP/1.0\r\nHost: 127.0.0.1\r\n\r\n";
        _ = stream.write(req) catch {
            std.Thread.sleep(poll_ms * std.time.ns_per_ms);
            continue;
        };

        // Read response (small buffer is enough for a health check)
        var buf: [256]u8 = undefined;
        const n = stream.read(&buf) catch {
            std.Thread.sleep(poll_ms * std.time.ns_per_ms);
            continue;
        };
        if (n > 12 and std.mem.startsWith(u8, buf[0..n], "HTTP/1.")) {
            // Check for "200" in the status line
            var line_end: usize = 0;
            for (buf[0..n], 0..) |c, i| {
                if (c == '\n') {
                    line_end = i;
                    break;
                }
            }
            const status_line = buf[9..line_end]; // skip "HTTP/1.x "
            if (std.mem.startsWith(u8, status_line, "200")) {
                return;
            }
        }
        last_err = error.NotReady;
        std.Thread.sleep(poll_ms * std.time.ns_per_ms);
    }
    _ = last_err;
    return error.HealthCheckTimeout;
}

/// Spawn nalar as a child process. The caller is responsible for calling terminate()
```

```zig
// tools/codegen_webapp_assets.zig
const std = @import("std");

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer _ = gpa.deinit();
    const allocator = gpa.allocator();

    var args = std.process.args();
    _ = args.next(); // skip exe name
    const dist_path = args.next() orelse return error.MissingDistPath;
    const out_path = args.next() orelse return error.MissingOutPath;

    var dist_dir = try std.fs.cwd().openDir(dist_path, .{ .iterate = true });
    defer dist_dir.close();

    // Collect all files into a flat list, relative paths
    var files: std.ArrayList([]const u8) = .empty;
    defer files.deinit(allocator);
    var walker = try dist_dir.walk(allocator);
    defer walker.deinit();
    while (try walker.next()) |entry| {
        if (entry.kind != .file) continue;
        const rel = try allocator.dupe(u8, entry.path);
        try files.append(rel, allocator);
    }

    // Sort for deterministic output
    std.mem.sort([]const u8, files.items, {}, lessThan);

    // Emit the generated file
    var out_dir = try std.fs.cwd().makeOpenPath(std.fs.path.dirname(out_path).?, .{});
    defer out_dir.close();
    var out_file = try out_dir.createFile(std.fs.path.basename(out_path), .{});
    defer out_file.close();

    var writer = out_file.writer();
    try writer.writeAll(
        \\// GENERATED by tools/codegen_webapp_assets.zig — DO NOT EDIT
        \\// To regenerate: zig build codegen:webapp-assets
        \\
        \\const std = @import("std");
        \\
        \\pub const Asset = struct {
        \\    /// Path as served by the webserver, e.g. "/assets/index-abc.js"
        \\    path: []const u8,
        \\    /// File contents (use as-is; do not modify).
        \\    content: []const u8,
        \\    /// Inferred MIME type with charset for text/* types.
        \\    mime: []const u8,
        \\};
        \\
    );

    try writer.writeAll("pub const assets: []const Asset = &.{\n");
    for (files.items) |rel| {
        const abs = try std.fs.path.join(allocator, &.{ dist_path, rel });
        defer allocator.free(abs);
        const content = try std.fs.cwd().readFileAlloc(allocator, abs, 10 * 1024 * 1024);
        const path_served = try std.fmt.allocPrint(allocator, "/{s}", .{rel});
        const mime = inferMime(rel);
        // Escape content for embedding in source — we use hex escapes for safety
        try writer.print("    .{{ .path = \"{s}\", .content = \"", .{path_served});
        for (content) |b| {
            // Escape bytes that would break a Zig string literal
            switch (b) {
                '"' => try writer.writeAll("\\\""),
                '\\' => try writer.writeAll("\\\\"),
                '\n' => try writer.writeAll("\\n"),
                '\r' => try writer.writeAll("\\r"),
                '\t' => try writer.writeAll("\\t"),
                0...7, 11, 12, 14...31 => try writer.print("\\x{x:0>2}", .{b}),
                32...126 => try writer.writeByte(b),
                else => try writer.print("\\x{x:0>2}", .{b}),
            }
        }
        try writer.print("\", .mime = \"{s}\" }},\n", .{mime});
    }
    try writer.writeAll("};\n");

    std.debug.print("Generated {s} with {d} assets\n", .{ out_path, files.items.len });
}

fn lessThan(_: void, a: []const u8, b: []const u8) bool {
    return std.mem.lessThan(u8, a, b);
}

fn inferMime(path: []const u8) []const u8 {
    // Same table as static_files.zig
    if (std.mem.endsWith(u8, path, ".html")) return "text/html; charset=utf-8";
    if (std.mem.endsWith(u8, path, ".css")) return "text/css; charset=utf-8";
    if (std.mem.endsWith(u8, path, ".js")) return "application/javascript; charset=utf-8";
    if (std.mem.endsWith(u8, path, ".mjs")) return "application/javascript; charset=utf-8";
    if (std.mem.endsWith(u8, path, ".json")) return "application/json; charset=utf-8";
    if (std.mem.endsWith(u8, path, ".svg")) return "image/svg+xml";
    if (std.mem.endsWith(u8, path, ".png")) return "image/png";
    if (std.mem.endsWith(u8, path, ".jpg") or std.mem.endsWith(u8, path, ".jpeg")) return "image/jpeg";
    if (std.mem.endsWith(u8, path, ".gif")) return "image/gif";
    if (std.mem.endsWith(u8, path, ".webp")) return "image/webp";
    if (std.mem.endsWith(u8, path, ".ico")) return "image/x-icon";
    if (std.mem.endsWith(u8, path, ".woff")) return "font/woff";
    if (std.mem.endsWith(u8, path, ".woff2")) return "font/woff2";
    if (std.mem.endsWith(u8, path, ".ttf")) return "font/ttf";
    if (std.mem.endsWith(u8, path, ".map")) return "application/json; charset=utf-8";
```

```zig
// src/apps/desktop_app/extraction.zig
const std = @import("std");
const builtin = @import("builtin");

/// A flat asset entry. Source: the generated webapp_assets.zig at comptime.
pub const AssetEntry = struct {
    path: []const u8,      // e.g. "/index.html" or "/assets/app.js"
    content: []const u8,
    mime: []const u8,
};

/// Extract the given assets to a fresh per-user temp dir.
/// Returns the absolute path of the temp dir.
pub fn extract(allocator: std.mem.Allocator, assets: []const AssetEntry) ![]u8 {
    const tmp_base = tmpDirBase(allocator);
    defer allocator.free(tmp_base);

    // Make a per-pid subdir so concurrent runs don't collide
    const subdir = try std.fmt.allocPrint(allocator, "nalar-desktop-webapp-{d}", .{std.os.linux.getpid()});
    defer allocator.free(subdir);

    const full_path = try std.fs.path.join(allocator, &.{ tmp_base, subdir });
    errdefer {
        std.fs.cwd().deleteTree(full_path) catch {};
        allocator.free(full_path);
    }

    try std.fs.cwd().makePath(full_path);

    // Write each asset
    for (assets) |asset| {
        // Strip the leading "/" from path
        const rel = if (asset.path.len > 0 and asset.path[0] == '/')
            asset.path[1..]
        else
            asset.path;

        const abs_path = try std.fs.path.join(allocator, &.{ full_path, rel });
        defer allocator.free(abs_path);

        // Make parent dirs as needed
        if (std.fs.path.dirname(abs_path)) |parent| {
            try std.fs.cwd().makePath(parent);
        }

        const file = try std.fs.createFileAbsolute(abs_path, .{});
        defer file.close();
        try file.writeAll(asset.content);
    }

    return full_path;
}

/// Recursively remove the temp dir. Best-effort: failures are logged but not propagated.
pub fn cleanup(allocator: std.mem.Allocator, dir: []const u8) void {
    std.fs.cwd().deleteTree(dir) catch |err| {
        std.log.warn("Failed to clean up temp dir {s}: {s}", .{ dir, @errorName(err) });
    };
    allocator.free(dir);
}

fn tmpDirBase(allocator: std.mem.Allocator) []u8 {
    const builtin_os = builtin.os.tag;
    return switch (builtin_os) {
        .linux => blk: {
            if (std.posix.getenv("XDG_RUNTIME_DIR")) |xdg| {
                break :blk allocator.dupe(u8, xdg) catch blk2: {
                    break :blk2 allocator.dupe(u8, "/tmp") catch unreachable;
                };
            }
```

```objc
#import <Cocoa/Cocoa.h>
#import <WebKit/WebKit.h>
#import <string.h>
#import "webview_c.h"

// Obj-C class definitions
@interface NalarAppDelegate : NSObject <NSApplicationDelegate>
@property(nonatomic, strong) NSWindow* window;
@property(nonatomic, strong) WKWebView* webView;
@property(nonatomic, copy) NSString* urlString;
@property(nonatomic, assign) const nalar_webview_asset* assets;
@property(nonatomic, assign) size_t asset_count;
@end

@implementation NalarAppDelegate

- (void)applicationDidFinishLaunching:(NSNotification*)notification {
    // Create the window
    NSRect frame = NSMakeRect(100, 100, self.config.width, self.config.height);
    NSWindowStyleMask style = NSWindowStyleMaskTitled | NSWindowStyleMaskClosable;
    if (self.config.resizable) style |= NSWindowStyleMaskResizable;
    if (self.config.minimizable) style |= NSWindowStyleMaskMiniaturizable;
    self.window = [[NSWindow alloc] initWithContentRect:frame
                                              styleMask:style
                                                backing:NSBackingStoreBuffered
                                                  defer:NO];
    [self.window setTitle:[NSString stringWithUTF8String:self.config.title]];
    [self.window setMinSize:NSMakeSize(self.config.min_width, self.config.min_height)];

    // Create the WKWebView
    WKWebViewConfiguration* wkconfig = [[WKWebViewConfiguration alloc] init];
    // Register a custom URL scheme handler for app://
    // (see WKNavigationDelegate below)
    self.webView = [[WKWebView alloc] initWithFrame:frame configuration:wkconfig];
    self.webView.navigationDelegate = self;

    [self.window setContentView:self.webView];
    [self.window makeKeyAndOrderFront:nil];

    // Load the URL
    NSURL* url = [NSURL URLWithString:[NSString stringWithUTF8String:self.urlString.UTF8String]];
    [self.webView loadRequest:[NSURLRequest requestWithURL:url]];
}

- (void)applicationShouldTerminateAfterLastWindowClosed:(NSApplication*)sender {
    return YES;
}

// Asset interception: if the URL starts with app://, serve from the asset table
- (void)webView:(WKWebView*)webView
    decidePolicyForNavigationAction:(WKNavigationAction*)navigationAction
    decisionHandler:(void (^)(WKNavigationActionPolicy))decisionHandler {
    NSString* url = navigationAction.request.URL.absoluteString;
    if ([url hasPrefix:@"app://"]) {
        // Find the path component
        NSString* path = [url substringFromIndex:[@"app://" length]];
        // Skip host: find first "/" after the host
        NSRange slash = [path rangeOfString:@"/"];
        if (slash.location != NSNotFound) {
            path = [path substringFromIndex:slash.location];
        } else {
            path = @"/";
        }

        // Linear search the asset table
        for (size_t i = 0; i < self.asset_count; i++) {
            const nalar_webview_asset* asset = &self.assets[i];
            if (strcmp(asset->path, path.UTF8String) == 0) {
                NSData* data = [NSData dataWithBytes:asset->content length:asset->content_len];
                NSString* mime = [NSString stringWithUTF8String:asset->mime];
                [webView loadData:data
                          MIMEType:mime
          characterEncodingName:@"utf-8"
                            baseURL:[NSURL URLWithString:@"app://localhost/"]];
                decisionHandler(WKNavigationActionPolicyCancel);
                return;
            }
        }

        // 404
        NSData* notFound = [@"Not Found" dataUsingEncoding:NSUTF8StringEncoding];
        [webView loadData:notFound MIMEType:@"text/plain"
            characterEncodingName:@"utf-8" baseURL:[NSURL URLWithString:@"app://localhost/"]];
        decisionHandler(WKNavigationActionPolicyCancel);
        return;
    }
    decisionHandler(WKNavigationActionPolicyAllow);
}

@end

// C ABI implementations
extern "C" nalar_webview* nalar_webview_create(
    const nalar_webview_config* cfg,
    const char* url
) {
    @autoreleasepool {
        [NSApplication sharedApplication];
        [NSApp setActivationPolicy:NSApplicationActivationPolicyRegular];

        NalarAppDelegate* delegate = [[NalarAppDelegate alloc] init];
        delegate.config = *cfg;
        delegate.urlString = [NSString stringWithUTF8String:url];
        delegate.assets = cfg->assets;
        delegate.asset_count = cfg->asset_count;

        [NSApp setDelegate:delegate];
        [NSApp activateIgnoringOtherApps:YES];

        return (nalar_webview*)delegate;  // Return as opaque
    }
}

extern "C" void nalar_webview_run(nalar_webview* wv) {
    @autoreleasepool {
        [NSApp run];
    }
}

extern "C" void nalar_webview_destroy(nalar_webview* wv) {
    NalarAppDelegate* delegate = (NalarAppDelegate*)wv;
    [delegate release];
    [NSApp terminate:nil];
}
```

```cpp
    wil::com_ptr<ICoreWebView2Controller> controller;
    wil::com_ptr<ICoreWebView2> webview;
    const nalar_webview_asset* assets;
    size_t asset_count;
    bool closed;
};

static LRESULT CALLBACK WndProc(HWND hwnd, UINT msg, WPARAM wp, LPARAM lp) {
    NalarWebview* wv = (NalarWebview*)GetWindowLongPtr(hwnd, GWLP_USERDATA);
    switch (msg) {
        case WM_CLOSE:
            wv->closed = true;
            PostQuitMessage(0);
            return 0;
        case WM_SIZE: {
            RECT rc;
            GetClientRect(hwnd, &rc);
            wv->controller->put_Bounds(rc);
            return 0;
        }
    }
    return DefWindowProc(hwnd, msg, wp, lp);
}

};

extern "C" nalar_webview* nalar_webview_create(
    const nalar_webview_config* cfg,
    const char* url
) {
    // 1. Register a window class
    WNDCLASS wc = {};
    wc.lpfnWndProc = WndProc;
    wc.hInstance = GetModuleHandle(NULL);
    wc.lpszClassName = L"NalarWebviewClass";
    RegisterClass(&wc);

    // 2. Create the window
    DWORD style = WS_OVERLAPPEDWINDOW;
    if (!cfg->resizable) style &= ~WS_MAXIMIZEBOX & ~WS_THICKFRAME;
    if (!cfg->minimizable) style &= ~WS_MINIMIZEBOX;
    HWND hwnd = CreateWindowEx(
        0, L"NalarWebviewClass", ..., style, ...
    );

    // 3. Allocate the handle
    auto* wv = new NalarWebview{ .hwnd = hwnd, .assets = cfg->assets, .asset_count = cfg->asset_count, .closed = false };
    SetWindowLongPtr(hwnd, GWLP_USERDATA, (LONG_PTR)wv);

    // 4. Initialize WebView2 (async)
    auto* env_opts = nullptr;
    CreateCoreWebView2EnvironmentWithOptions(
        nullptr, nullptr, nullptr,
        Callback<ICoreWebView2CreateCoreWebView2EnvironmentCompletedHandler>(
            [wv, url, cfg](HRESULT result, ICoreWebView2Environment* env) -> HRESULT {
                env->CreateCoreWebView2Controller(wv->hwnd, ...);
                // On controller created: register the asset request handler,
                // set user agent, navigate to URL.
                return S_OK;
            }).Get()
    );

    ShowWindow(hwnd, SW_SHOW);
    return (nalar_webview*)wv;
}

extern "C" void nalar_webview_run(nalar_webview* wv_ptr) {
    NalarWebview* wv = (NalarWebview*)wv_ptr;
    MSG msg;
    while (GetMessage(&msg, NULL, 0, 0) > 0) {
        TranslateMessage(&msg);
        DispatchMessage(&msg);
    }
}

extern "C" void nalar_webview_destroy(nalar_webview* wv_ptr) {
    NalarWebview* wv = (NalarWebview*)wv_ptr;
    wv->controller->Close();
    DestroyWindow(wv->hwnd);
    delete wv;
}
```

> **NOTE for implementer:** WebView2 is the most code of the three platforms because it is COM-based and async-initialized. Expect 400-600 LOC for a production-quality implementation. Critical pitfalls:
>
> 1. **Async initialization race** — `CreateCoreWebView2EnvironmentWithOptions` is async; you cannot navigate to the URL until the callback fires. The classic mistake: navigate immediately, fail, debug for an hour.
> 2. **COM apartment** — `CoInitializeEx(NULL, COINIT_APARTMENTTHREADED)` must be called before any WebView2 API. Call it in `nalar_webview_create`.
> 3. **Custom URI scheme via `ICoreWebView2WebResourceRequestEventHandler`** — register with `add_WebResourceRequested` and respond with a custom `ICoreWebView2WebResourceResponse` containing a memory stream of the asset bytes.
> 4. **WebView2Loader.dll** must be in the same dir as `nalar-desktop.exe` at runtime, OR linked statically (the static-link NuGet is much larger but simpler distribution).
> 5. **Window message handling** — `WM_SIZE` must update the controller bounds or the webview won't reflow when the user resizes the window.

```zig
// src/apps/desktop_app/main.zig
const std = @import("std");
const cli = @import("cli.zig");
const port = @import("port.zig");
const path_resolve = @import("path_resolve.zig");
const subprocess = @import("subprocess.zig");
const extraction = @import("extraction.zig");
const webview = @import("webview.zig");

// Generated by build (Chunk 3.2 codegen)
const webapp_assets = @import("embedded/webapp_assets.zig");

pub fn main(init: std.process.Init) !void {
    const allocator = init.gpa;

    // 1. Parse CLI
    const args = init.minimal.args;
    var cfg = cli.parse(allocator, args) catch |err| switch (err) {
        error.ShowHelp => return,
        else => {
            std.log.err("Failed to parse CLI args: {s}", .{@errorName(err)});
            return err;
        },
    };
    defer cfg.deinit(allocator);

    // 2. Find the nalar binary
    const self_path = path_resolve.selfExePath(allocator) catch |err| {
        std.log.err("Failed to determine self path: {s}", .{@errorName(err)});
        return err;
    };
    defer allocator.free(self_path);

    const path_env = std.posix.getenv("PATH") orelse "";
    const nalar_path = path_resolve.resolve(allocator, cfg.nalar_path, self_path, path_env) orelse {
        std.log.err("Could not find the nalar binary. Searched:", .{});
        if (cfg.nalar_path) |p| std.log.err("  --nalar-path: {s}", .{p});
        std.log.err("  next to self: {s}/nalar", .{std.fs.path.dirname(self_path) orelse "."});
        std.log.err("  PATH: {s}", .{path_env});
        return error.NalarNotFound;
    };
    defer allocator.free(nalar_path);

    // 3. Allocate a port (or use the explicit one)
    const listen_port: u16 = if (cfg.port == 0)
        (port.findFree(allocator) catch |err| {
            std.log.err("Failed to find a free port: {s}", .{@errorName(err)});
            return err;
        }).port
    else
        cfg.port;

    // 4. Extract the embedded webapp to a temp dir
    const asset_entries = buildAssetEntries(allocator) catch |err| {
        std.log.err("Failed to build asset entries: {s}", .{@errorName(err)});
        return err;
    };
    var webapp_dir = extraction.extract(allocator, asset_entries) catch |err| {
        std.log.err("Failed to extract embedded webapp: {s}", .{@errorName(err)});
        return err;
    };
    defer extraction.cleanup(allocator, webapp_dir);

    // 5. Spawn nalar
    var nalar = subprocess.spawn(allocator, nalar_path, listen_port) catch |err| {
        std.log.err("Failed to spawn nalar: {s}", .{@errorName(err)});
        return err;
    };
    defer nalar.terminate();

    // 6. Wait for nalar to be healthy
    std.log.info("Waiting for nalar at http://127.0.0.1:{d}...", .{listen_port});
    subprocess.waitForHealth(allocator, listen_port, 10_000, 100) catch |err| switch (err) {
        error.HealthCheckTimeout => {
            std.log.err("nalar did not become healthy within 10s. Is --static-dir working?", .{});
            return err;
        },
        else => return err,
    };
    std.log.info("nalar is ready.", .{});

    // 7. Build the C ABI config
    const title_z = try allocator.dupeZ(u8, cfg.title);
    defer allocator.free(title_z);
    const ua_z: ?[*:0]const u8 = if (cfg.user_agent) |ua| blk: {
        break :blk try allocator.dupeZ(u8, ua);
    } else null;
    defer if (ua_z) |ua| allocator.free(ua);

    // Convert the comptime asset list to a runtime C array
    var c_assets: [webapp_assets.assets.len]webview.CAsset = undefined;
    for (webapp_assets.assets, 0..) |asset, i| {
        c_assets[i] = .{
            .path = @as([*:0]const u8, asset.path.ptr),
            .content = asset.content.ptr,
            .content_len = asset.content.len,
            .mime = @as([*:0]const u8, asset.mime.ptr),
        };
    }

    const webview_cfg: webview.Config = .{
        .title = title_z.ptr,
        .width = @intCast(cfg.window_width),
        .height = @intCast(cfg.window_height),
        .min_width = 400,
        .min_height = 300,
        .resizable = true,
        .maximizable = true,
        .minimizable = true,
        .user_agent = ua_z,
        .icon_path = null,
        .assets = &c_assets,
        .asset_count = c_assets.len,
    };

    // 8. Run the webview (blocks until window closed)
    const url = try std.fmt.allocPrint(allocator, "http://127.0.0.1:{d}/", .{listen_port});
    defer allocator.free(url);
    std.log.info("Opening webview at {s}", .{url});
    webview.run(allocator, webview_cfg, url) catch |err| {
        std.log.err("Webview error: {s}", .{@errorName(err)});
        return err;
    };
    std.log.info("Window closed. Exiting.", .{});
}

/// Convert the comptime-generated asset list into a runtime slice of `AssetEntry`.
/// This is a thin adapter so extraction.zig does not need to know about comptime.
fn buildAssetEntries(allocator: std.mem.Allocator) ![]const extraction.AssetEntry {
    _ = allocator;
    // The comptime assets are static; we just return a slice of the array.
    // `AssetEntry` is layout-compatible with the generated `Asset` struct.
    return @as([]const extraction.AssetEntry, @ptrCast(webapp_assets.assets));
}
```

## Pitfalls & gotchas (consolidated)

1. **Asset hash filenames** — Vite produces filenames like `assets/index-abc123.js` with content hashes. The codegen step must run AFTER `bun run build`. The dependency chain in build.zig handles this; the implementer must not skip `codegen_step.dependOn(&build_webapp_step.step)`.

2. **WebKitGTK scheme handler runs on the main thread** — do not block it. The asset table is borrowed (not copied), so the caller must keep it alive for the lifetime of the webview.

3. **WebView2 async init** — `CreateCoreWebView2EnvironmentWithOptions` returns immediately and signals completion via callback. The URL navigation MUST happen in the callback, not after the call. The classic bug is "navigate immediately, end up with a blank webview".

4. **macOS NSApp.run blocks the main thread** — there is no way to recover from inside the call. The window-close signal must call `[NSApp terminate:]` to break out of the loop.

5. **Extracted temp dir is per-pid** — concurrent runs don't collide, but a crashed run leaves the dir on disk. The next run with the same pid could pick up stale files. For v1 this is acceptable; for v2 add a content-hash suffix.

6. **The `webapp_assets.zig` content is committed into the binary** — for a 1 MB Vue dist, the binary grows by ~1 MB. After zig build, check `ls -la zig-out/bin/nalar-desktop` to confirm. If you need a smaller binary, gzip the assets and decompress in the shim handler (Option β from the design doc).

7. **--port 0 is auto-pick, but the user can still pin** — the nalar CLI's `--port 0` (in main.zig) opens on a random port. Our wrapper allocates a port via the kernel, then passes it as `--port NNNN` to nalar. The race window between closing our probe socket and nalar binding is small but non-zero — on a busy system, a different process could grab the port. For v1 this is acceptable.

8. **No JSON config file** — v1 is CLI-only. The next iteration could add `~/.config/nalar-desktop/config.json` for persistent settings (last window size, last nalar port, etc.). Out of scope for v1.

9. **No multi-window** — one `nalar-desktop` instance opens one window pointing at one nalar. Multi-window is a v2 feature.

10. **Code signing not done** — macOS Gatekeeper will block unsigned apps from a fresh download. Windows SmartScreen will warn. For development (`./zig-out/bin/nalar-desktop` from a terminal) this is fine. For distribution, signing is required.
