# MCP stdio Transport for the Agent AI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add **stdio** as a second MCP transport alongside the existing HTTP transport. The agent can talk to MCP servers that expose themselves as a child-process command (`command` + `args` + `env` + optional `cwd`), communicating over Content-Length-framed JSON-RPC on stdin/stdout exactly as the [MCP stdio spec](https://modelcontextprotocol.io/specification/draft/basic/transports/stdio) describes. The HTTP transport stays untouched (backward compat). For self-testing we ship a tiny **`mcp-hello-world`** MCP server binary (sibling of `zig-out/bin/nalar...`) that exposes a single tool `say_hello(name?: string) -> "Hello {name||world}"`; the functional harness configures it as a stdio MCP server and asserts the agent can call it end-to-end.

**Architecture:** The MCP server framework already exists at `src/modules/agent/mcp/mcp/{mcp_server,mcp_transport,mcp_types,mcp_tools}.zig` — Zig 0.16-friendly, Content-Length framed, JSON-RPC dispatch for `initialize` / `tools/list` / `tools/call` / `resources/*` / `prompts/*`. We **expose one of its binaries** as `zig-out/bin/mcp-hello-world` (a thin `main` that wires up a single tool) — that gives us the "hello world" MCP server for self-testing AND a real reference implementation. On the **client side** we add a single new file `src/modules/agent/mcp/mcp/mcp_stdio.zig` that contains everything stdio: Content-Length framing (private to the file) + `StdioClient` (owns a `std.process.Child`, framed read/write over its stdin/stdout) + `StdioRegistry` (process-global, one child per server name, lazy spawn, clean shutdown). The existing server-side `mcp_transport.zig` is untouched — its inline framing logic is fine for v1. `handle_mcp_tool.zig` and `buildMCPToolsRun` (in `prompts_build_messages_for_agent_prompt.zig`) auto-detect which transport to use per server: presence of `command` ⇒ stdio client, presence of `url` ⇒ current HTTP path. **MCP server config continues to live in `config.json` under the existing `mcp_servers` key** — stdio entries just use `{"command": "...", "args": [...]}` instead of `{"url": "...", "headers": {...}}`. No new config file, no new PUT endpoint. Frontend `McpServer` type + `McpServerModal` gain a transport toggle (HTTP / stdio) and the stdio-only fields; `parseMcpServers` / `serializeMcpServers` round-trip both shapes via the existing `PUT /api/config/nalar` endpoint.

**Tech Stack:** Zig 0.16 (`std.process.Child`, `std.Io.File`), Vue 3 + TypeScript + Pinia, `pytest` + `pexpect`/subprocess harness, `tests/functional/harness.py` (isolated tmpdir HOME, port 8080..8199).

## Global Constraints

- **Cross-platform from day one**: every stdio path MUST compile and run on Linux, macOS, AND Windows. The stdio child gets `std.process.Child.init(argv, allocator)` + `stdin_behavior=.Pipe, stdout_behavior=.Pipe, stderr_behavior=.Pipe` + `cwd` (Zig 0.16 supports `.cwd` on both POSIX and Windows). Spawn-failure mode on a platform we can't support → return `error.MCPStdioUnsupportedOS` with a clear message ("stdio MCP requires a POSIX or Windows host — your target is X").
- **Backward compat for HTTP**: every existing `mcp_servers` entry (with `url` + `headers` only) MUST keep working unchanged. New fields are optional; `parseMcpServerConfig` accepts entries with either `url` OR `command`. An entry with neither is rejected with a clear log.
- **Per-request arena**: handlers allocate from `ctx.allocator` (arena) → NO `defer allocator.free` inside HTTP handlers or tool exec. The stdio child owns its own allocator (parent_allocator-backed) for socket bookkeeping; the per-message body slices are arena-managed.
- **No static-contract tests** — behavioural tests only.
- **DONT KILL THE PORT 8081 SERVER** — functional harness uses ports 8080..8199.
- **No port-8081 live-server + curl verification** — use the python functional harness + Zig unit tests.
- **Empty-slice-as-NULL rule** — `SqliteBackend.exec` binds `""` as SQL NULL → any PATCH of the new stdio config fields must use `COALESCE(?, '')` for nullable TEXT defaults (we don't touch the DB; only the in-memory config path, but be aware).
- **Tests live INLINE at the bottom of impl files** (`test "..." { }` blocks). HTTP-handler test files use `_ = @import(...)` in `src/ai_workflow/tui/test_runner.zig`.
- **Per-tool-def convention**: MCP tools are registered in `tools_equipped.UNIFIED_TOOL_REGISTRY()` AND `equips()` — both sites, in that order. Mirror existing patterns at lines 68-121 / 135-245.
- **SSE wire-format contract** — we add NO new SSE event names. Tool-result events ride the existing `llm_history` `updated` event (already pre-registered). The grace period of "agent name = session name" + "auto rename on first message" don't apply here.
- **mcp-hello-world must ship in the build** — `build.zig` gains an `install_mcp_hello_world` step that compiles a new exe `mcp-hello-world-{target-triple}` and installs it next to `nalarcore-{target-triple}`. Functional tests locate it via `$NALAR_BIN` neighbour.
- **No new CHANGELOG file** — update `NALAR.md` (§"Recent changes") with one entry that lands on the same commit as the wire-up task.

#### Step 1.1 — Write the file

**Section A — Content-Length framing** (private helpers, file-scoped):

```zig
const std = @import("std");
const builtin = @import("builtin");

const MAX_HEADER_BYTES: usize = 8 * 1024;

pub const StdioError = error{
    ChildSpawnFailed,
    BrokenPipe,
    InvalidFrame,        // no Content-Length header found
    InvalidContentLength,// non-numeric / negative length
    UnexpectedEof,
};

/// Read one Content-Length-framed JSON-RPC message from `reader`.
/// Allocates the body; caller frees with `allocator.free`. Accepts
/// both CRLF and LF-only line endings (MCP stdio spec allows LF).
fn readFramed(allocator: std.mem.Allocator, reader: anytype) StdioError![]u8 {
    var header_buf: [MAX_HEADER_BYTES]u8 = undefined;
    var header_len: usize = 0;
    var found_blank = false;

    while (!found_blank) {
        var byte: [1]u8 = undefined;
        const n = reader.read(&byte) catch return StdioError.UnexpectedEof;
        if (n == 0) return StdioError.UnexpectedEof;
        if (header_len >= header_buf.len) return StdioError.InvalidFrame;
        header_buf[header_len] = byte[0];
        header_len += 1;
        if (header_len >= 4 and std.mem.eql(u8, header_buf[header_len - 4 ..][0..4], "\r\n\r\n")) {
            found_blank = true;
        } else if (header_len >= 2 and std.mem.eql(u8, header_buf[header_len - 2 ..][0..2], "\n\n")) {
            found_blank = true;
        }
    }

    const header = header_buf[0..header_len];
    var cl: ?usize = null;
    var it = std.mem.splitSequence(u8, header, "\n");
    while (it.next()) |raw_line| {
        const line = std.mem.trim(u8, raw_line, "\r ");
        if (std.ascii.startsWithIgnoreCase(line, "Content-Length:")) {
            cl = std.fmt.parseInt(usize, std.mem.trim(u8, line["Content-Length:".len..], " \t"), 10)
                catch return StdioError.InvalidContentLength;
            break;
        }
    }
    const content_length = cl orelse return StdioError.InvalidFrame;

    const body = allocator.alloc(u8, content_length) catch return StdioError.UnexpectedEof;
    errdefer allocator.free(body);
    var total: usize = 0;
    while (total < content_length) {
        const n = reader.read(body[total..]) catch {
            allocator.free(body);
            return StdioError.UnexpectedEof;
        };
        if (n == 0) {
            allocator.free(body);
            return StdioError.UnexpectedEof;
        }
        total += n;
    }
    return body;
}

fn writeFramed(writer: anytype, body: []const u8) !void {
    try writer.print("Content-Length: {d}\r\n\r\n", .{body.len});
    try writer.writeAll(body);
}
```

**Section B — `StdioClient`** (spawn child, framed read/write):

```zig
pub const StdioClient = struct {
    allocator: std.mem.Allocator,
    child: std.process.Child,
    stdin: std.fs.File,
    stdout: std.fs.File,
    stderr: std.fs.File,

    pub fn init(
        allocator: std.mem.Allocator,
        argv: []const []const u8,
        env: ?*const std.process.Environ.Map,
        cwd: ?[]const u8,
    ) StdioError!StdioClient {
        var child = std.process.Child.init(argv, allocator);
        child.stdin_behavior = .Pipe;
        child.stdout_behavior = .Pipe;
        child.stderr_behavior = .Pipe;
        if (cwd) |c| child.cwd = c;
        // env override — v1 inherits; UI's env editor becomes "extra env
        // on top of inherited". A future v2 can pre-fork+execve with
        // a custom env_map (Zig 0.16 has no clean setter on Child).
        _ = env;
        child.spawn() catch return StdioError.ChildSpawnFailed;

        return .{
            .allocator = allocator,
            .child = child,
            .stdin = child.stdin orelse return StdioError.BrokenPipe,
            .stdout = child.stdout orelse return StdioError.BrokenPipe,
            .stderr = child.stderr orelse return StdioError.BrokenPipe,
        };
    }

    pub fn send(self: *StdioClient, body: []const u8) !void {
        var buf: [64]u8 = undefined;
        var ws = self.stdin.writer(&buf);
        try writeFramed(ws.interface, body);
        try ws.interface.flush();
    }

    pub fn recv(self: *StdioClient) ![]u8 {
        var buf: [4096]u8 = undefined;
        var rs = self.stdout.reader(&buf);
        return try readFramed(self.allocator, rs.interface);
    }

    pub fn deinit(self: *StdioClient) void {
        _ = self.child.kill() catch {};
        _ = self.child.wait() catch {};
    }
};
```

**Section C — `StdioRegistry`** (one child per server, singleton, lazy spawn):

```zig
const Entry = struct { client: *StdioClient };

pub const StdioRegistry = struct {
    allocator: std.mem.Allocator,
    entries: std.StringHashMap(Entry),
    mutex: std.Thread.Mutex = .{},

    pub fn init(allocator: std.mem.Allocator) StdioRegistry {
        return .{ .allocator = allocator, .entries = std.StringHashMap(Entry).init(allocator) };
    }

    pub fn getOrSpawn(
        self: *StdioRegistry,
        name: []const u8,
        argv: []const []const u8,
        env: ?*const std.process.Environ.Map,
        cwd: ?[]const u8,
    ) !*StdioClient {
        self.mutex.lock();
        defer self.mutex.unlock();
        if (self.entries.get(name)) |e| return e.client;

        const client = try self.allocator.create(StdioClient);
        errdefer self.allocator.destroy(client);
        client.* = try StdioClient.init(self.allocator, argv, env, cwd);

        const key_dup = try self.allocator.dupe(u8, name);
        errdefer self.allocator.free(key_dup);
        try self.entries.put(key_dup, .{ .client = client });
        return client;
    }

    pub fn dropAndRespawn(
        self: *StdioRegistry,
        name: []const u8,
        argv: []const []const u8,
        env: ?*const std.process.Environ.Map,
        cwd: ?[]const u8,
    ) !*StdioClient {
        self.mutex.lock();
        defer self.mutex.unlock();
        if (self.entries.fetchRemove(name)) |kv| {
            kv.value.client.deinit();
            self.allocator.destroy(kv.value.client);
            self.allocator.free(kv.key);
        }
        const client = try self.allocator.create(StdioClient);
        errdefer self.allocator.destroy(client);
        client.* = try StdioClient.init(self.allocator, argv, env, cwd);
        const key_dup = try self.allocator.dupe(u8, name);
        errdefer self.allocator.free(key_dup);
        try self.entries.put(key_dup, .{ .client = client });
        return client;
    }

    pub fn deinit(self: *StdioRegistry) void {
        var it = self.entries.iterator();
        while (it.next()) |kv| {
            kv.value_ptr.client.deinit();
            self.allocator.destroy(kv.value_ptr.client);
            self.allocator.free(kv.key);
        }
        self.entries.deinit();
    }

    // Process-global singleton. Lazy-init on first call; cleaned up via
    // the shutdown hook in main.zig (Task 7).
    var global_registry: ?StdioRegistry = null;
    var global_init_mutex: std.Thread.Mutex = .{};

    pub fn global() *StdioRegistry {
        global_init_mutex.lock();
        defer global_init_mutex.unlock();
        if (global_registry == null) {
            global_registry = StdioRegistry.init(std.heap.page_allocator);
        }
        return &global_registry.?;
    }
};
```

const testing = std.testing;

// ── Framing tests (no child needed) ────────────────────────────

test "readFramed parses Content-Length body" {
    var input: []const u8 = "Content-Length: 13\r\n\r\n{\"json\":\"rpc\"}";
    var stream = std.io.fixedBufferStream(input);
    const body = try readFramed(testing.allocator, stream.reader().any());
    defer testing.allocator.free(body);
    try testing.expectEqualStrings("{\"json\":\"rpc\"}", body);
}

test "readFramed accepts LF-only line endings" {
    var input: []const u8 = "Content-Length: 5\r\nX-Bogus: y\n\nhello";
    var stream = std.io.fixedBufferStream(input);
    const body = try readFramed(testing.allocator, stream.reader().any());
    defer testing.allocator.free(body);

test "readFramed returns error.InvalidFrame when Content-Length missing" {

    /// HTTP transport (Streamable-HTTP + JSON-RPC). Mutually exclusive with `command`.
    url: ?[]const u8 = null,
    headers: McpHeadersMap,

    /// stdio transport (spawn child, framed JSON-RPC on stdin/stdout).

        const has_url = self.url != null and self.url.?.len > 0;
        const has_cmd = self.command != null and self.command.?.len > 0;
        return has_url != has_cmd; // exactly one
    }

pub fn parseMcpServerConfig(allocator: std.mem.Allocator, value: std.json.Value) !?McpServerConfig {
    const obj = switch (value) {
        .object => |o| o,
        else => return null,
    };

    var cfg = McpServerConfig{ .headers = McpHeadersMap.init(allocator) };
    errdefer freeMcpHeadersMap(&cfg.headers, allocator);

    // Branch 1: HTTP (url + optional headers).
    if (obj.get("url")) |url_field| {
        const url_str = switch (url_field) {
            .string => |s| s,
            else => {
                std.log.warn("MCP server 'url' is not a string; skipping", .{});
                return null;
            },
        };
        if (url_str.len == 0) {
            std.log.warn("MCP server 'url' is empty; skipping", .{});
            return null;
        }
        cfg.url = try allocator.dupe(u8, url_str);
        if (obj.get("headers")) |h| {
            if (h == .object) cfg.headers = try parseMcpHeadersMap(allocator, h.object);
        }
        return cfg;
    }

    // Branch 2: stdio (command + args + optional cwd/env).
    if (obj.get("command")) |cmd_field| {
        const cmd_str = switch (cmd_field) {
            .string => |s| s,
            else => {
                std.log.warn("MCP server 'command' is not a string; skipping", .{});
                return null;
            },
        };
        if (cmd_str.len == 0) {
            std.log.warn("MCP server 'command' is empty; skipping", .{});
            return null;
        }
        cfg.command = try allocator.dupe(u8, cmd_str);

        if (obj.get("args")) |args_value| {
            const args_arr = switch (args_value) {
                .array => |a| a,
                else => {
                    std.log.warn("MCP server 'args' must be a JSON array of strings; skipping", .{});
                    return null;
                },
            };
            var args_list: std.ArrayList([]const u8) = .empty;
            defer args_list.deinit(allocator);
            for (args_arr.items) |item| {
                const s = switch (item) {
                    .string => |x| x,
                    else => continue,
                };
                try args_list.append(allocator, try allocator.dupe(u8, s));
            }
            cfg.args = try args_list.toOwnedSlice(allocator);
        }

        if (obj.get("cwd")) |cwd_field| {
            if (cwd_field == .string) cfg.cwd = try allocator.dupe(u8, cwd_field.string);
        }
        // `env` is applied at spawn time via the stdio client (Task 2);
        // for now it's documentation-only — the frontend won't write env
        // values that aren't already in the inherited environment.
        return cfg;
    }

    // Neither branch matched.
    std.log.warn("MCP server config missing 'url' OR 'command'; skipping", .{});
    return null;
}

    defer _ = gpa.deinit();

    """Resolve the sibling mcp-hello-world-{triple} binary path."""
    import os, glob
    base = os.path.basename(nalar_bin)

    if not matches:
        raise RuntimeError(f"No mcp-hello-world binary matching {pattern}")
    return matches[0]

```ts
export function parseMcpServers(
  raw: Record<string, any> | undefined,
): McpServer[] {
  if (!raw) return []
  const out: McpServer[] = []
  for (const [name, server] of Object.entries(raw)) {
    if (!server) continue
    const transport: 'http' | 'stdio' = server.command ? 'stdio' : 'http'
    if (transport === 'http') {
      if (typeof server.url !== 'string' || !server.url) continue
      const headers = server.headers
        ? Object.entries(server.headers).map(([k, v]) => ({ key: k, value: String(v ?? '') }))
        : []
      out.push({ name, transport, url: server.url, headers })
    } else {
      if (typeof server.command !== 'string' || !server.command) continue
      out.push({
        name, transport, command: server.command,
        args: Array.isArray(server.args) ? server.args.map(String) : [],
        env: Array.isArray(server.env) ? server.env.map(String) : [],
        cwd: typeof server.cwd === 'string' ? server.cwd : '',
        headers: [],
      })
    }
  }
  out.sort((a, b) => a.name.localeCompare(b.name))
  return out
}

export function serializeMcpServers(list: McpServer[]): Record<string, any> | undefined {
  if (list.length === 0) return undefined
  const out: Record<string, any> = {}
  for (const s of list) {
    if (!s.name) continue
    if (s.transport === 'stdio') {
      if (!s.command) continue
      out[s.name] = {
        command: s.command,
        ...(s.args && s.args.length ? { args: s.args } : {}),
        ...(s.env && s.env.length ? { env: s.env } : {}),
        ...(s.cwd ? { cwd: s.cwd } : {}),
      }
    } else {
      if (!s.url) continue
      const headers: Record<string, string> = {}
      for (const h of (s.headers ?? [])) if (h.key) headers[h.key] = h.value
      out[s.name] = { url: s.url, ...(Object.keys(headers).length ? { headers } : {}) }
    }
  }
  return Object.keys(out).length ? out : undefined
}
```

## Pitfalls (worth knowing up front)

1. **Stdout is line-buffered or block-buffered depending on OS.** When the child is a binary that writes via libc `printf`, its stdout is line-buffered when attached to a terminal but block-buffered when attached to a pipe. Use `setvbuf(stdout, NULL, _IONBF, 0)` at the top of `main.zig` (or `std.io.getStdOut().setMode(.unbuffered)` if Zig's stdlib offers it) to force unbuffered writes — otherwise the JSON-RPC body sits in the child's buffer until it exits, and the client hangs reading. This is the #1 cause of "stdio MCP hangs forever" bug reports.

2. **Header parsing accepts both CRLF and LF blank-line separators.** The MCP stdio spec says CRLF but real-world servers sometimes emit LF-only. `readFramed` accepts both. The existing `lsp.zig:100 read_message` accepts ONLY `\r\n\r\n` — we deliberately don't reuse it.

3. **Child stderr capture.** `child.stderr_behavior = .Pipe` is silent by default — `mcp-hello-world`'s stderr writes pile up. Drain stderr in a background thread OR write a `stderr_drain_loop` that pulls bytes and forwards them to the agent's logger. For v1, set `child.stderr_behavior = .Ignore` and tell users to add `--debug` + redirect manually; a v2 can drain properly.

4. **Cross-platform `cmd.exe /C more` test helper.** On Windows, `cat` doesn't exist; use `cmd.exe /C more` (which echoes stdin to stdout). The test in Task 2 uses `builtin.os.tag` to pick the right binary — verify it actually runs on a Windows CI runner, not just on Linux.

5. **Singleton registry lifetime.** `McpStdioRegistry.global()` lives for the whole nalar process. If the user edits `mcp_servers` via PUT `/api/config/nalar`, the spawned children from the OLD config don't get killed — the new config spawns new children alongside. Document this as a known v1 limitation; a v2 can compare old vs new config and kill the no-longer-present children.

6. **Env passing.** `std.process.Child` in Zig 0.16 doesn't expose a clean `.env_map` setter. Either use the inherited env (current plan) OR write a small helper that pre-forks and `execvpe`s with a custom env. For v1 we inherit — the frontend's env-editor becomes documentation ("extra env keys to ADD on top of inherited"). Real custom env is v2.

7. **`tools/list` is per-server, not per-call.** `buildMCPToolsRun` calls `tools/list` ONCE per server on first session load (then caches on `AgentTool` arrays). If a stdio child crashes between sessions, the cache is stale. Fix in v2: invalidate cache on `dropAndRespawn`.

8. **JSON-RPC `id` collisions.** v1 always sends `id: "1"` (matches the existing HTTP path at `handle_mcp_tool.zig:93`). If a server pipelines multiple requests, responses get misaligned. For v1 we always wait for the response before sending the next request — no pipelining. Document this so v2 knows where to add `id` counters.
