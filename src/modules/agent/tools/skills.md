# Agent Skills

These skills are loaded on-demand via the `get_skill` tool.

<!-- SKILL: code_review -->
## Code Review Skill

When reviewing code:
1. Check for potential bugs and edge cases
2. Verify error handling is comprehensive
3. Ensure memory safety (no leaks, proper cleanup)
4. Look for security vulnerabilities
5. Validate the code follows project conventions
<!-- END_SKILL -->

<!-- SKILL: debugging -->
## Debugging Skill

When debugging issues:
1. Reproduce the issue reliably first
2. Isolate the problem with minimal test cases
3. Check logs and error messages for clues
4. Use binary search to narrow down problematic code
5. Verify the fix doesn't introduce new issues
<!-- END_SKILL -->

<!-- SKILL: documentation -->
## Documentation Skill

When writing documentation:
1. Start with a clear summary of purpose
2. Include practical examples
3. Document parameters and return values
4. Note any side effects or edge cases
5. Keep it concise but complete
<!-- END_SKILL -->
